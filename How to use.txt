How to use

1. Launch the app with run.bat
2. Paste one or more YouTube URLs, or add local media files
3. Choose summary language:
   - Chinese (Traditional)
   - English
4. Click Start
5. Use Pause / Resume / Stop as needed
6. Results appear on the right side
7. Use Save As / Copy / Open Output Folder when done

Behavior summary:
- If good subtitles are available, the app prefers subtitle-based transcript
- If subtitles are missing, Whisper transcription is used
- Chinese output is normalized to Traditional Chinese
- Long media automatically uses faster transcription settings

GPU 閃退保護 / Native Crash Isolation
----------------------------------------
新版預設啟用獨立轉錄子程序：
- MEDIA2TXT_TRANSCRIBE_SUBPROCESS=1
- GPU 預設 compute type：int8_float16
- 15 分鐘以上使用長片低負載策略
- 40 分鐘以上使用超長片策略

當 CUDA / CTranslate2 發生 Windows 0xC0000005 原生閃退時：
1. 主 UI 不會一起關閉
2. GPU 子程序失敗會被偵測
3. 自動建立 CPU 子程序重試
4. 單支任務仍由原本批次錯誤隔離機制處理

建議模式：
- Auto / GPU Auto：日常使用，GPU int8_float16，失敗自動 CPU fallback
- CPU Only：完全不用 CUDA，最穩定但較慢
- Low Resource：更低 beam / best_of，適合長影片或顯存較小電腦
- GPU Check Only：只檢查 CUDA DLL 與環境
