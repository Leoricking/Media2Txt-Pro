Media2Txt Pro Community - Install Guide

1. Install Python 3.10 or newer
2. Install requirements:
   pip install -r requirements.txt
3. Install Ollama and make sure it is running locally
4. Download a faster-whisper model and place it under:
   models\faster-whisper-large-v3
5. Optional but recommended:
   install ffmpeg and add it to PATH
6. Run:
   run.bat

Home PC (no .venv):
- run.bat will use system python
- GPU will be attempted first if available

Company PC (.venv):
- if .venv\Scripts\python.exe exists, run.bat will use it automatically
- use run_cpu.bat if you want to force CPU

Low resource mode:
- use run_low_resource.bat

Windows GPU 穩定性設定
------------------------
run.bat 會自動設定：
  MEDIA2TXT_TRANSCRIBE_SUBPROCESS=1
  MEDIA2TXT_GPU_COMPUTE_TYPE=int8_float16
  MEDIA2TXT_CPU_COMPUTE_TYPE=int8
  MEDIA2TXT_LONG_VIDEO_MINUTES=15
  MEDIA2TXT_VERY_LONG_VIDEO_MINUTES=40

這些設定可避免 faster-whisper / CTranslate2 發生 native crash 時連主 UI 一起關閉。
如果 GPU 子程序發生 EXIT_CODE=-1073741819 (0xC0000005)，主程式會自動改用 CPU 子程序重試。

若要手動恢復 float16（不建議 RTX 3060 長影片批次）：
  set MEDIA2TXT_GPU_COMPUTE_TYPE=float16

若要停用子程序隔離（不建議）：
  set MEDIA2TXT_TRANSCRIBE_SUBPROCESS=0
